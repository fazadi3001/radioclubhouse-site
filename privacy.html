Who we are

Radio Clubhouse (رادیو کلاب هاوس) is an independently operated radio project at https://radioclubhouse.com. Contact: fama301@gmail.com.

YouTube API Services

Radio Clubhouse uses YouTube API Services to create and manage its own YouTube live broadcasts on its own YouTube channel. Use of those services is subject to the YouTube Terms of Service and the Google Privacy Policy.

What this website collects

This website collects no personal data from listeners beyond standard server logs (for example IP address, time, and the page requested) that are generated automatically when you visit the site. There are no listener accounts and no advertisements. We do not sell data.

YouTube API data

Data obtained through YouTube API Services is limited to metadata for the operator’s own channel broadcasts (such as titles and broadcast identifiers). That data is stored only on the operator’s own computer, for creating and managing those broadcasts. It is not sold and is not used to build profiles of listeners.

Revoking access

YouTube API access is used only by the operator to manage Radio Clubhouse’s own channel. If that Google or YouTube access was granted, it can be revoked at any time at https://security.google.com/settings/security/permissions.
